# Créditos das capturas de tela

As imagens desta pasta são capturas do app rodando num **emulador Android**, com
**dados de demonstração**: os animais, nomes, referências e registros de cuidado são
**fictícios**; as localizações são pontos aproximados em bairros de João Pessoa – PB.

O mapa é © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.
